# M3 checklist: files and boards

M3a (this part) is the pure `wc-gcode` crate: loading, comment and realtime sanitising, the home shift, the T rule,
the restart state and sequence, the 3D preview payload and boards. CI checks it against `tests/fixtures/gcode/` and
`tests/fixtures/boards/`. It has no routes yet and never opens the serial port, so nothing here can move the
machine. The on-machine part of M3 ("a 100k-line file loads and previews within 2× Python's time, and a backup made
by Rust restores in Python") needs the M3b routes; step 2 gives an early read of the time budget on the Pi.

You need: the Mac with this branch checked out, `pip install ziglang` done once, and the Pi booted from the microSD
card (`pi@maslow-next.local`) with the Python service running. Leave the router switched off.

## 1. CI

- [ ] `cd rust && cargo test -p wc-gcode` passes: every `tests/fixtures/gcode/*.json`, `stream.json` and
      `tests/fixtures/boards/*.json` case matches (floats within 1e-9, every gcode string exactly).
- [ ] `.venv/bin/python -m pytest -q tests/test_gcode_fixtures.py` passes, so the fixtures still match Python.
- [ ] `rust/scripts/coverage.sh` reports `wc-gcode` at or above 95%.

## 2. Time on the Pi (no routes needed)

- [ ] Make a 100k-line file on the Mac:
      `python3 -c "import math;print('G21 G90');[print(f'G1 X{(10+i*.004)*math.cos(i*.01):.4f} Y{(10+i*.004)*math.sin(i*.01):.4f} Z-1 F1200') for i in range(100000)]" > ~/big.nc`
      (or use a real job of that size).
- [ ] Build the timer: `cd rust && cargo zigbuild --release --target aarch64-unknown-linux-gnu.2.36 -p wc-gcode --example gcode_timing`.
- [ ] Copy both: `scp rust/target/aarch64-unknown-linux-gnu/release/examples/gcode_timing ~/big.nc pi@maslow-next.local:/tmp/`.
- [ ] `ssh pi@maslow-next.local /tmp/gcode_timing /tmp/big.nc 0 0`. Note `total` and the line, Z move and payload
      counts.
- [ ] With a stopwatch, open the same file in the Python UI (`http://maslow-next.local:5000/next/`, Open G-code) and
      time from Open to the preview drawn. The Rust `total` is well under twice that. (This leaves out HTTP and the
      socket on the Rust side; step 3 is the full comparison.)
- [ ] `ssh pi@maslow-next.local rm /tmp/gcode_timing /tmp/big.nc`.

## 3. After the M3b routes land (later PR)

- [ ] `wc-switch rust`, open the same 100k-line file from the UI: it loads and previews within twice the Python time
      from step 2, and the preview looks the same as Python's.
- [ ] Set a home, then compare a few lines of the shifted file with Python's at the same home.
- [ ] Make a backup from Rust, `wc-switch python`, restore it: the settings and files come back.
