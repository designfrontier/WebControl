# M5 checklist: calibration

M5a (this part) is the pure maths: `wc-kinematics` and `wc-calibration`, checked in CI against
`tests/fixtures/calibration/`. It has no routes yet, so nothing here touches the Pi, the controller or the router.
The on-machine part of M5 ("holey calibration from saved measurements gives the same numbers as Python (±1e-3)
and the accept writes the same `$` lines") is done from the UI once the M5 routes land; until then, step 2 makes the
same comparison on the Mac with your real settings.

You need: the Mac with this branch checked out and the last holey or triangular measurements you entered (the
numbers on the calibration form, or from the log).

## 1. CI

- [ ] `cd rust && cargo test -p wc-kinematics -p wc-calibration` passes: all four fixture files within their
      tolerances (`kinematics.json` 1e-9; `holey_calibrate.json` 1e-3 on `Opt_*` and 1e-6 on `totalError`;
      `triangular_calculate.json` 1e-6; `accept_commands.json` line for line).
- [ ] `rust/scripts/coverage.sh` reports `wc-kinematics` and `wc-calibration` at or above 95%.

## 2. Your settings, Python against Rust (on the Mac, never on the original file)

- [ ] Copy the settings from the Pi: `mkdir -p ~/m5-home && scp -r pi@maslow-next.local:.WebControl ~/m5-home/`.
- [ ] Holey: `cd rust && cargo run -p wc-calibration --example calibrate -- ~/m5-home holey M1 M2 … M12` with your
      twelve measurements. Note the four values and the `$` lines.
- [ ] Enter the same twelve numbers in the Python UI's holey calibration (`/next/calibration/holey`, Calculate,
      do **not** Accept). Each of motor spacing, motor Y offset and the two chain tolerances is within 0.001 of
      the Rust value.
- [ ] The `$2`, `$3`, `$40` and `$41` lines Rust printed are the values Python would save (Python shows them
      rounded to 5 places; any setting already equal to the result has no line).
- [ ] Triangular, if you use it: the same with `triangular cut12 cut34 cut5 bitDiameter`; the motor Y offset,
      rotation radius and chain sag match Python exactly, and the lines end with `G21 `, `G90 `, `G40 `,
      `G0 X0 Y0 `.
- [ ] `rm -r ~/m5-home`.

## 3. After the M5 routes land (later PR)

- [ ] `wc-switch rust`, open `/next/calibration/holey`, enter the saved measurements, Calculate: the same numbers
      as step 2. Accept, then `$$` from the console shows `$2`, `$3`, `$40`, `$41` with those values.
      `wc-switch python`.
